# N15. 반복 실행과 복구 표준화

**실행하지 않은 제안입니다.**

## 확인하려는 질문

반복 실행·장애 복구·평가 기록을 공통 도구로 묶으면 실험 운영이 쉬워지는가?

## 사용할 도구와 준비할 일

- 사용 후보: NeMo Evaluator
- 기존 준비 기록: 기존 runner 대조군은 있으나 Evaluator 연동과 동일 scorer 계약은 미구현.

위 기록은 제안을 정리할 당시의 설치/API 확인 수준입니다. 실제 비교 결과나 기능 지원을 입증한 실행 기록은 아닙니다.
