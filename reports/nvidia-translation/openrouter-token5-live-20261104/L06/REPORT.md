# L06. 문서마다 모델을 선택하면 고정 Luna보다 나은가

**Switchyard는 이 네 문서에서 고정 Luna보다 비용이 낮았지만, 종합 조건 충족은 4/4에서 2/4로 줄었습니다. 품질을 유지한 비용 절감으로 볼 수 없어 운영 적용은 보류합니다.**

### 기준선과 실험 조건

기술 블로그 네 편의 원문 전체를 다음 네 방식으로 번역했습니다. Luna는 gpt-5.6-luna, Qwen은 qwen/qwen3.7-flash입니다.

| 조건 | 모델을 어떻게 정했나 |
|---|---|
| 기준선: 항상 Luna | 모든 문서를 Luna로 번역 |
| 항상 Qwen | 모든 문서를 Qwen으로 번역 |
| 규칙 | 길이·코드 블록·링크 수를 보고 선택. 이 네 편은 모두 Luna 선택 |
| Switchyard | NeMo Switchyard 분류기가 난도를 판단. 두 편은 Luna, 두 편은 Qwen 선택 |

이전에 받은 OpenAI 결과 10개와 나중에 실행한 Qwen 결과 6개를 합친 비교입니다. 후속 실행에서는 분류기를 다시 호출하지 않고 이미 내려진 선택을 유지했습니다. 따라서 ‘추가 실행 6건’은 새 실험 여섯 종류가 아니라, 위 표의 빈 모델·문서 조합 여섯 개를 채운 것입니다.

### 기준선과 비교한 결과

| 조건 | 중대 오류 없음 | 코드 보존 | URL 보존 | 종합 조건 충족 |
|---|---:|---:|---:|---:|
| 기준선: 항상 Luna | 4/4 | 4/4 | 4/4 | 4/4 |
| 항상 Qwen | 2/4 | 3/4 | 3/4 | 1/4 |
| 문서 특징에 따른 규칙 | 3/4 | 4/4 | 4/4 | 3/4 |
| Switchyard 모델 선택 | 3/4 | 4/4 | 3/4 | 2/4 |

이 문서의 **종합 조건 충족**은 같은 평가 대상이 다음 세 가지를 **모두** 만족했다는 뜻입니다.

1. 평가 모델이 중대 오류(major)를 0건으로 보고함.
2. Markdown에서 추출한 코드가 원문과 동일함.
3. 링크·이미지의 URL이 원문과 동일함.

예를 들어 Switchyard의 2/4는 문서 네 편 중 두 편이 이 세 조건을 모두 만족했다는 뜻입니다. 경미한 오류(minor)는 남아 있을 수 있고, 사람이 승인했다는 뜻도 아닙니다. 코드 주석 번역도 코드 동일성 위반으로, 내부 목차 링크 변경도 URL 동일성 위반으로 셉니다.

### 어느 문서에서 달라졌나

| 원문 | 항상 Luna | 항상 Qwen | 규칙 | Switchyard |
|---|---|---|---|---|
| Mistral Large 4 | 충족 | 코드 변경·URL 변경 | 충족 | URL 변경 |
| Project ProtoStar | 충족 | 중대 2건 | 중대 1건 | 충족 |
| MPS in PyTorch 2.15 | 충족 | 중대 2건 | 충족 | 충족 |
| AnyLanguageModel 1.0 | 충족 | 충족 | 충족 | 중대 1건 |

규칙도 같은 Luna를 골랐지만 번역을 새로 요청했기 때문에 고정 Luna와 결과가 달랐습니다. Switchyard의 Mistral 문서는 Luna를 골랐는데도 내부 URL이 바뀌었고, AnyLanguageModel 문서는 Qwen을 골라 중대 오류가 남았습니다. 모델 선택만으로 코드·URL 보호를 대신할 수는 없습니다.

Qwen의 Mistral 결과는 코드 주석을 한국어로 바꾸고 목차의 내부 anchor를 바꿨습니다. 실행 코드를 파손하거나 외부 URL을 다른 곳으로 바꿨다는 뜻은 아닙니다. ProtoStar의 금액은 원문 $190 billion=1,900억 달러인데 후보는 190억 달러=$19 billion으로 10배 작게 옮겼습니다. 평가 모델의 ‘100배’라는 설명은 계산 오류여서 해석에 사용하지 않았습니다.

### 적용 판단

이 표본에서는 항상 Qwen이 가장 저렴했지만 기준선의 품질을 유지하지 못했습니다. Switchyard도 고정 Luna를 대체할 근거가 부족합니다. 단순한 문서는 저가 모델을 쓰되 코드·URL 보호와 실패 후 재검사를 붙이는 방식이 다음 검증 후보입니다.

기존 OpenAI 결과와 새 Qwen 결과는 모델 평가의 시점·문맥이 달라 엄격히 통제한 품질 순위는 아닙니다. 위 수치는 실제 관찰을 나란히 놓은 비교입니다.
