# 후속 Qwen 비교 16건 결과

**기존 11개 실험 중 L06~L09에서 비어 있던 Qwen 조건을 실행했습니다. 별도의 실험16종이 아니라 번역 요청16회입니다.** 처음 받은 Luna 결과와 함께 비교해야 의미가 있으므로 아래 개별 보고서는 기준선까지 합친 결과를 담습니다.

L06의6회는 고정 Qwen4문서와 Switchyard가 Qwen을 고른2문서입니다. L07의3회는 각 응답에8문단을 담아 총24개를 평가했습니다. L08은5문단을 한 번씩 고쳤습니다. L09는 두 시나리오에서 변경 문단을 한 번씩 번역했고, 기존 이웃을 붙여 평가했습니다. 합계16회입니다.

## 종합 조건 충족은 무엇인가

표에서 ‘4/5 충족’은 다섯 평가 대상 중 네 개가 다음 조건을 **모두** 만족했다는 뜻입니다.

1. 평가 모델이 중대 오류(major)를0건으로 보고했다.
2. 코드가 원문과 같다.
3. 링크와 이미지의 URL이 원문과 같다.

경미한 오류(minor)는 남아 있을 수 있습니다. 예를 들어 L07은 세 조건 모두8/8이라 이 지표로 차이를 구별하지 못합니다. 그래서 경미한 오류 수도 함께 비교했습니다. 수정 전 문단과 수정 후 문단을 혼동하지 않도록 L08에는 수정 전 참고값도 제공합니다.

## 결과를 어떻게 사용할까

이번 표본에서는 Switchyard의 비용 절감이 품질 유지로 이어지지 않았습니다. Data Designer의 예시 생성·선별·연결은 작동했지만 예시6개를 더 넣은 번역이 나아졌다는 근거는 없습니다. 변경 문단만 번역하고 조립하는 경로는 작동했으나 가상 변경 두 건만 확인했습니다.

41개 평가 단위에 사람 정답은 없습니다. 기존 Luna와 후속 Qwen의 평가 시점·문맥도 달라 엄격한 성능 순위로 일반화하지 않습니다. 코드 주석 번역과 내부 목차 URL 변경은 동일성 위반으로 셌으며 실행 코드 파손·외부 URL 변조로 확대 해석하지 않았습니다. 평가자의 숫자 환산 오류도 개별 보고서에서 바로잡았습니다.
