## 수치 읽는 법

‘중대 오류 없음·보존’은 같은 문서 또는 문단에서 **모델이 중대 오류를 0건으로 보고했고, 코드와 URL도 원문과 같은 경우**입니다. 4/5는 다섯 평가 대상 중 네 개가 세 조건을 모두 만족했다는 뜻입니다. 경미한 문제는 남아 있을 수 있습니다. 링크 설명 개수, 잘못 통과시킨 오류 후보 수처럼 다른 지표는 각 보고서에서 별도로 정의했습니다.

## 지금 적용할 만한 것은 무엇인가

링크 설명을 번역 모델에 보여주는 기존 방향과, 수정 대상·읽기 전용 문맥을 구분하는 방법은 유지하거나 후속 비교할 근거가 있습니다. Guardrails의 자동 수락만으로 번역을 반영하는 방식은 부족했고, Switchyard의 저가 모델 선택도 이 표본에서 고정 Luna의 품질을 유지하지 못했습니다. Data Designer 예시 추가의 품질 이득은 관찰하지 못했습니다.

모든 결과는 이미 개발에 사용한 작은 표본과 모델 평가에 따른 관찰입니다. 사람 정답 승인 수는0이며, 운영 품질 보장이나 통계적 우위를 뜻하지 않습니다. 원격 PR #256의 자동 루프는 재개하지 않았습니다.
