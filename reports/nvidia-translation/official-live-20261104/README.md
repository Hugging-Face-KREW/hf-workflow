## 이번 실행에서 확인한 것

- Guardrails 계약과 직접 Python 검사는 동일 판정을 냈지만, L02 F2에서 문장의 설명을 누락하고 링크만 남긴 후보도 함께 승인했습니다. 프레임워크 일치와 번역 품질 성공은 다릅니다. 원출력과 판정을 보존했습니다.
- L05는 39개 노출된 회귀·합성 입력으로 내장 facts/quality와 직접 검사를 비교했습니다. 과거 이름이 `new_synthetic_diagnostic`인 split도 이번에는 재사용한 입력입니다. 사람 정답이나 신규 held-out 결과가 아닙니다.
- Switchyard L06은 4문서에서 10개 번역 완료, 6개 비OpenAI arm 차단입니다. L08은 Luna 수정 5개 완료·선택된 비OpenAI 수정 5개 차단, L09는 전체/부분 갱신 4개 완료·비OpenAI 2개 차단입니다. 차단을 번역 실패나 파싱 실패로 합치지 않았고, 누락/중복 coverage 오류는 없습니다. 저가 모델 대비 비용·품질 우위는 아직 결론낼 수 없습니다.
- Data Designer는 실제 공식 API 호출 8회로 8행 생성했고 별도 모델 검토에서 6행 사용 가능 판정을 받았습니다. 계획 B 번역 대조군의 Qwen은 대체하지 않고 차단했습니다. 따라서 데이터 생성 편의성은 확인했지만 번역 품질 개선 효과는 미측정입니다.
- L10은 24개 문단의 링크 전체 보호/URL만 보호를 새로 비교했습니다. 양쪽 불변항목 24/24 유지, 남은 영어 설명 라벨 28→1입니다. 의미 품질 검증은 없으며 현재 운영에는 이미 라벨을 번역기에 보여 주는 보호 방식이 반영돼 있습니다. NVIDIA 효과나 새로운 운영 개선으로 주장하지 않습니다.
