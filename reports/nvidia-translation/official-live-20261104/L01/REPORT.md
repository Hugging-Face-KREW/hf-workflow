# L01. 지적받은 링크 설명만 고칠 수 있는가

**한 문장의 영어 링크 설명을 한국어로 바꾸는 데 성공했습니다. 다만 비교 조건이 없는 연결 확인용 실험입니다.**

### 무엇을 어떻게 실행했나

이 실험에는 별도 기준선을 두지 않았습니다.

기술 블로그 번역에서 `dataset card`라는 링크 설명이 영어로 남은 문장 1개를 사용했습니다. gpt-5-mini-2025-08-07에 원문·기존 번역·해당 오류 지적을 주고, 나머지는 유지한 채 해당 문장만 고치게 했습니다.

| 항목 | 수정 전 | 수정 후 |
|---|---|---|
| 링크 설명 | dataset card | 데이터셋 카드 |
| 주변 설명 | 각 결과의 정확한 의미를 확인할 수 있다는 문장 | 유지 |
| 검사 결과 | 별도 평가하지 않음 | 직접 검사와 NeMo Guardrails 모두 수락 |

### 결과를 어떻게 해석하나

수정문 생성과 검사 연결이 작동한 사례입니다. 수정하지 않은 조건을 별도 평가하지 않았으므로 오류 수정률이나 Guardrails의 품질 우위를 계산할 수는 없습니다. 같은 함수에 기반한 직접 검사와 Guardrails의 판정이 일치했다는 점을 확인했습니다. 피드백이 없는 조건과의 비교는 다음 L02에서 다룹니다.
