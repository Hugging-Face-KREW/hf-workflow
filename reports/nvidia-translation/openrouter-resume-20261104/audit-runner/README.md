# 날짜별 감사·재개 준비 소스

이 파일들은 실제 준비·무료 검증에 사용한 소스 스냅샷입니다. 현재 로컬 경로, 기존 미게시 runner와 고정 예시 파일에 의존하므로 독립 배포 도구가 아닙니다. prepare.py는 유료 호출 없이 과거 차단된 16개 payload만 고정합니다. audit_readonly.py는 정상 인증 헤더를 쓰는 공식 GET만 수행하며 계정 숫자 스냅샷은 저장소 밖 0600 파일에만 남깁니다. 재실행할 필요는 없습니다.

프로덕션 예산 원장과 provider 계약은 미승인 상태이며 유료 실행 CLI를 제공하지 않습니다. test_resume.py의 승인·비용 숫자는 네트워크가 차단된 fixture입니다. 실제 비용 확인이나 결제 설정 변경을 대신하지 않습니다.

검증: 네트워크 차단 pytest 28개 통과. prepare.main 전체 준비와 L07의 6개 예시 경로, 30개 프로세스 동시 예약, 중복/불확실/재시도/상한/모델·provider identity를 포함합니다.
